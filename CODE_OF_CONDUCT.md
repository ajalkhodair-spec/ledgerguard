# Code of Conduct

## Standard

Project participation must remain professional, respectful, and focused on technical work. Harassment, discrimination, threats, publication of private information, and deliberate disruption are not acceptable.

## Enforcement

Maintainers may remove content, restrict participation, or reject contributions that violate this standard. Report conduct concerns privately to the repository owner. Reports will be reviewed as promptly and confidentially as practical.

## Scope

This standard applies to repository discussions, pull requests, reviews, issues, and project-related communication in other public or private channels.
