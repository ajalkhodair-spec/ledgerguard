# Security Policy

## Scope

This repository is a research proof of concept. It has not been assessed for production deployment, physical-device safety, hardware-backed key protection, or production PKI operation.

## Reporting

Report suspected vulnerabilities through a private GitHub security advisory. Include the affected revision, reproduction steps, expected behavior, observed behavior, and any proof-of-concept input. Do not open a public issue for an unpatched vulnerability.

## Supported Version

Security fixes are applied to the latest `main` revision. V1 is retained for evidence compatibility; new protocol work targets V2.

## Disclosure

Please allow a reasonable remediation period before public disclosure. Test only systems and data you own or are authorized to assess.
