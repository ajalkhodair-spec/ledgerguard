# LedgerGuard v2.0.0-poc

LedgerGuard `v2.0.0-poc` is a research-software release of the permissioned-ledger firmware-governance proof of concept and its reviewer-evidence evaluation framework.

## Included

- V1 contracts and the security-focused V2 protocol implementation.
- Four-validator local Hyperledger Besu and IPFS orchestration.
- Threshold approval, signer and device revocation, guarded rollout transitions, authenticated terminal receipts, and complete-cohort witnessed commitments.
- HTTP/SQLite comparison, software-device cohort experiments, application-shaped local IPFS experiments, cache reuse, contract security tests, concurrency checks, and validator process-crash trials.
- Reproduction scripts, compact sanitized public evidence, final publication figures, plot-level figure data, and provenance metadata.

## Release Assets

- Comprehensive results workbook.
- Full reviewer-revision evidence archive.
- Evidence manifest and SHA-256 checksums.
- Complete PDF, SVG, and 600 dpi PNG Results figure bundle.

## Evidence Boundary

This release supports a controlled local research PoC. It does not represent physical-device or hardware-backed-key testing, a multi-host WAN deployment, active Byzantine validator injection, production load testing, formal verification, an independent security audit, or production readiness. Software-device cohort sizes describe authenticated logical identities and are not counts of simultaneously operating physical devices. Network profiles use application-level delay and read pacing around local IPFS transfers rather than OS-level network emulation or observed WAN paths. Fleet-scale accountability rows are analytical calculations grounded in compiler storage layouts and locally executed gas medians.

See `REPRODUCIBILITY.md`, `docs/experimental_setup.md`, `docs/evidence_freeze.md`, and the release evidence manifest for exact commands, configurations, evidence classifications, and remaining limitations.
